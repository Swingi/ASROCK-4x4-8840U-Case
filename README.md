# ASROCK 4X4 BOX-8840U Case

## Current part: one-piece bottom

The bottom is designed as a **single printable part** containing:

- 170 x 170 mm bottom plate
- 10 mm plate thickness
- four integral 40 mm feet
- central 150 x 150 mm ventilation / lamella field
- perimeter plug-in guides for the side walls
- reinforced guide corners

The future upper part will be one single printed part consisting of the lid and all four side walls. It will plug into the guides on this bottom; there is no separate lid part and no separate side-wall printing.

## FreeCAD

Run `build_bottom.py` from the FreeCAD Python console. It creates:

- `output/freecad/ASROCK_4x4_bottom.FCStd`
- `output/step/ASROCK_4x4_bottom.step`
- `output/stl/ASROCK_4x4_bottom.stl`

The dimensions are centralized in `config.py`.
